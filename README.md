# HMI 26.2 Remake

HMI 26.2 Remake is a remake and continuation of the HMI (Hold My Items) Minecraft mod, updated specifically for Minecraft 26.2 using Fabric.

The purpose of the mod is to improve item and inventory management while keeping the normal Minecraft gameplay experience intact. HMI focuses on small quality-of-life improvements that make handling items faster and more convenient without adding unnecessary gameplay mechanics.

## About

HMI was originally created to make interacting with items in Minecraft more convenient. This remake brings the concept forward for Minecraft 26.2 and updates the mod to work with the newer Minecraft and Fabric systems.

The mod is intended to feel like a natural part of Minecraft rather than changing the way the game is played.

## Features

HMI provides improvements focused around item and inventory interaction.

Some of the main goals of the mod include:

* Faster item management
* Easier access to items
* Improved inventory interaction
* More convenient item switching
* Better support for building
* Better support for survival gameplay
* Quality-of-life improvements for PvP and combat
* A simple interface that fits Minecraft's existing design

The exact features available may depend on the current version of the remake.

## Minecraft 26.2 Support

This version of HMI has been developed for Minecraft 26.2.

It is not intended to be used with older Minecraft versions unless a separate compatible build is provided.

Minecraft 26.2 introduced changes to the game's internal code, mappings, rendering systems, and modding environment. Because of this, simply changing the version number of an older HMI build is not enough to make it compatible. The remake updates the required code for the newer version.

## Fabric

HMI 26.2 Remake is a Fabric mod.

You need a Minecraft 26.2 Fabric installation to use it. Required dependencies, such as Fabric API, should also be installed if they are required by the current build.

## Client-Side

HMI is primarily designed as a client-side quality-of-life mod.

The goal is to improve the player's own inventory and item interaction without changing the core mechanics of the server.

Whether the mod can be used on a particular server depends on the features enabled and the server's rules.

## Installation

1. Install Minecraft 26.2.
2. Install Fabric Loader for Minecraft 26.2.
3. Install any required dependencies.
4. Place `HMI 26.2 Remake.jar` inside your Minecraft `mods` folder.
5. Start Minecraft using the Fabric profile.

On Windows, the mods folder is normally located at:

`%appdata%\.minecraft\mods`

## Compatibility

HMI 26.2 Remake is intended for:

* Minecraft 26.2
* Fabric
* Java Edition

Using an HMI version made for another Minecraft version may result in crashes, missing features, or other compatibility problems.

If Minecraft crashes after installing the mod, check the crash report and latest.log before reporting the issue.

## Reporting Issues

When reporting a problem, include:

* Minecraft version
* HMI version
* Fabric Loader version
* Fabric API version
* Other installed mods
* Crash report or latest.log
* A description of what happened
* Steps to reproduce the problem

This makes it much easier to identify and fix compatibility issues.
